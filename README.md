# CodeAlpha Task 2 - Exploratory Data Analysis

## Project Overview

This project is completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task is to perform Exploratory Data Analysis (EDA) on a dataset of 1,000 books collected from the Books to Scrape website.

The analysis focuses on understanding book prices, ratings, data quality, and patterns in the dataset.

## Dataset

The dataset contains 1,000 book records with the following columns:

- Title
- Price
- Rating
- Availability
- Product_URL

## Data Quality Check

The dataset was checked for:

- Missing values
- Duplicate records
- Data types
- Dataset structure

### Results

- Total records: **1,000**
- Total columns: **5**
- Missing values: **0**
- Duplicate records: **0**

## Exploratory Analysis

The analysis was performed to understand:

- Distribution of book prices
- Distribution of book ratings
- Average price for each rating
- Minimum and maximum book prices
- Overall patterns in the dataset

## Key Findings

- Minimum book price: **£10.00**
- Maximum book price: **£59.99**
- Average book price: **£35.07**
- Median book price: **£35.98**

### Rating Distribution

- 1 Star: **226 books**
- 2 Stars: **196 books**
- 3 Stars: **203 books**
- 4 Stars: **179 books**
- 5 Stars: **196 books**

The rating distribution shows that 1-star books have the highest count in this dataset.

## Visualizations

The project includes the following visualizations:

1. **Price Distribution**
   - Shows how book prices are distributed.

2. **Rating Distribution**
   - Shows the number of books for each rating.

3. **Average Price by Rating**
   - Compares the average price of books across different ratings.

## Conclusion

The EDA helped identify the structure, data quality, price distribution, and rating patterns of the 1,000-book dataset.

This analysis demonstrates basic data cleaning, statistical analysis, and data visualization skills using Python.
